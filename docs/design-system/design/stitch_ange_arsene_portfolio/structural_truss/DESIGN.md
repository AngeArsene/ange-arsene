## Brand & Style

This design system channels structural engineering discipline, architectural blueprint schematics, and developer-centric technical minimalism. Built for a bilingual engineering portfolio, it highlights precision, system architecture, and technical craft without decorative visual clutter.

### Aesthetic Principles
- **Engineering Blueprint Precision:** The visual language uses calibrated alignment, hairline structural dividers, low-opacity schematic coordinate grids, and rigorous geometric rhythm.
- **Architectural Dark Room:** Deep navy and slate blue surfaces emulate high-end terminal IDEs and architectural CAD software operating in high-efficiency dark work environments.
- **Code & Craft Hybrid:** Technical system monospace type anchors headers, badges, metadata, and structural schematics, counterbalanced by an articulate humanist sans body for bilingual prose (French/English).
- **Intentional Contrast:** Vibrant cyan accents emphasize pivotal architectural keywords and active terminal states against a muted structural backdrop.

## Colors

The palette uses structural deep sea navy tones combined with cyan tracer accents.

- **Foundations:** The canvas operates strictly on `#0B1A2B`, establishing a deep darkroom backdrop. Surfaces tier directly upward to `#0F2338` for primary containers and `#16324E` for nested modules, code headers, and alternate row banding.
- **Borders & Schematics:** Hairline framing is built with `#22496B` for structural card framing and grid rules, rising to `#4681B2` for active borders and selected focus rings.
- **Typography:** `#D7E7F4` delivers crisp high-legibility text, while `#7FA2C0` subdues labels, specs, and metadata without loss of readability.
- **Accents:** `#5FD0E6` commands immediate focal priority for key highlighted terms, active interactive components, and vital node links, with `#7FE0F2` reserved for interactive hover and spotlight states. Text on accent surfaces uses `#0B1A2B`.
- **System States:** Operational telemetry relies on `#5FE6A8` (passed checks, live status), `#C9A24A` (warnings, constraints), and `#4C6FE0` (informational notes).

## Typography

The typography pairs an engineering system monospace (`JetBrains Mono`) with a legible humanist sans (`Fira Sans`). Monospace carries structural titles, system statistics, project tags, and code logic. The humanist body guarantees fatigue-free reading across technical case studies in both English and French.

### Accent-Colored Phrases
Key technical nouns and architectural paradigms in headlines are wrapped with an inline accent token (`#5FD0E6`). For instance: `See your database <span class="text-accent">structure</span>, live.` or `Conception de systèmes <span class="text-accent">distribués</span>.`

## Layout & Spacing

A structured layout based on a base-4 grid system ensures predictable structural alignment.

- **Blueprint Grid Background:** Outer canvas and focal showcase areas use a subtle coordinate grid pattern (`rgba(70, 129, 178, 0.08)` hairline rules spaced at 24px increments) overlaid on `#0B1A2B`.
- **Layout Model:** A 12-column modular grid with standard 24px gutters on desktop and 16px margins on mobile screens, constrained to a max content column of 1200px.
- **Section Rhythm:** Major sections use generous vertical spacing (`space-16` to `space-24`) to give projects room to breathe, while internal card components maintain compact, dense spacing ratios (`space-3` to `space-4`).

## Elevation & Depth

Visual hierarchy is maintained without drop shadows or blurred casts. Depth is governed strictly through surface nesting and hairline structural stroke definitions.

- **Flat Blueprint Philosophy:** `box-shadow` is set to `none` system-wide.
- **Surface Layering:**
  - Base level: `canvas` (`#0B1A2B`).
  - Container tier: `surface` (`#0F2338`) bordered with 1px hairline `border` (`#22496B`).
  - Active/Interactive tier: `surface-alt` (`#16324E`) bordered with `border-strong` (`#4681B2`).
- **Dividers & Connectors:** Internal cell divisions, table outlines, and schematic connector lines use razor-thin 1px stroke widths rendered in `#22496B`.

## Shapes

The shape hierarchy combines engineering geometry with functional radiuses.

- **Cards & Architectural Panels:** Use 12px default corner radiuses, expanding to 16px for full-width featured hero modules.
- **Buttons & Control Elements:** Strict 8px radiuses balance precise technical form with tactile surface expectations.
- **Badges & Inline Chips:** Set to 4px radiuses to preserve the sharp, compact nature of hardware serial plates and terminal pills.

## Components

### Buttons
- **Primary:** Background `#5FD0E6`, text `#0B1A2B`, border none, 8px radius, font JetBrains Mono 14px weight 600. On hover, background shifts to `#7FE0F2`.
- **Secondary / Outline:** Background transparent, text `#D7E7F4`, 1px border `#22496B`, 8px radius. On hover, background becomes `#16324E` with border `#4681B2` and text `#5FD0E6`.
- **Terminal Action Button:** Compact font, `#0F2338` background, 1px border `#22496B`, includes left-aligned prompt indicator (`$` or `>`).

### Cards
- Container built on `#0F2338` with 1px border `#22496B` and 12px or 16px border radius.
- Header segments inside cards use `#16324E` bottom-bordered with `#22496B` to house repository titles, dates, or system specs.
- Interactive cards elevate border color to `#4681B2` on hover without translation or box-shadow shifts.

### Chips & Badges
- **Technical Tag:** Monospaced 11px uppercase, letter-spacing 0.05em, 4px radius, padded 2px 8px. Background `rgba(34, 73, 107, 0.45)`, 1px border `#22496B`, text `#7FA2C0`.
- **Live Status Badge:** Displays a 6px status dot (`#5FE6A8`), 4px radius, `#0F2338` background, `#22496B` border.

### Input Fields & Terminal Consoles
- **Inputs:** `#0B1A2B` background with 1px `#22496B` border, 8px radius, text `#D7E7F4`, placeholder `#7FA2C0`. On focus, border highlights to `#5FD0E6` with a crisp 1px outline offset.
- **Terminal Shell Block:** `#0B1A2B` shell container with top bar displaying window controls and active branch tag, monospace code font `#D7E7F4`, with accent `#5FD0E6` highlighted execution arguments.

### Bilingual Toggle Switch
- Segmented control enclosed in `#0F2338` with 1px `#22496B` border and 6px internal radius. Selected language (`EN` / `FR`) activates `#16324E` background with `#5FD0E6` monospace label and `#4681B2` hairline border.
